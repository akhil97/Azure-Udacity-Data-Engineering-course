# Azure Udacity Data Engineering Course

This repository contains projects, exercises, and notes completed as part of the **Udacity Data Engineering with Microsoft Azure** program. It brings together hands-on implementations across cloud data engineering concepts such as data lakes, data warehouses, ETL/ELT pipelines, analytics engineering, and NoSQL data modeling.

## Overview

The goal of this repository is to document practical work completed during the course and to showcase applied skills in designing and building modern data platforms on Azure. The projects cover core areas such as data ingestion, transformation, storage, modeling, and analytics using Azure-native services and related data engineering tools.

## Repository Structure

This repository currently includes the following project folders:

- `Azure-pipelines-nyc-payroll-analytics`
- `Building an Azure Data Lake for Bike Share Analytics`
- `Building an Azure Data Warehouse for Bike Share Data Analytics`
- `Data Modelling with Apache Cassandra`

Each folder focuses on a different data engineering problem and demonstrates the end-to-end workflow of working with structured or semi-structured data in cloud and distributed environments.

## Projects

### 1. Azure Pipelines – NYC Payroll Analytics

This project focuses on building a data pipeline for payroll analytics use cases. It typically involves ingesting raw data, transforming it into analysis-ready formats, and preparing it for reporting or downstream consumption.

**Key concepts:**
- Data ingestion and orchestration
- Cloud-based transformation workflows
- Analytics-ready dataset creation
- Pipeline automation

### 2. Azure Data Lake for Bike Share Analytics

This project demonstrates how to build a scalable Azure-based data lake architecture for bike share data. It usually includes raw data landing, curated storage layers, and transformation workflows for analytical access.

**Key concepts:**
- Data lake architecture
- Storage design and partitioning
- Batch data processing
- Analytical data preparation

### 3. Azure Data Warehouse for Bike Share Data Analytics

This project focuses on building a cloud data warehouse solution for reporting and business analytics. It generally includes schema design, loading curated datasets, and optimizing data for query performance.

**Key concepts:**
- Dimensional modeling
- Fact and dimension tables
- ELT/ETL workflows
- Query optimization for analytics

### 4. Data Modelling with Apache Cassandra

This project explores NoSQL data modeling using Apache Cassandra. It is centered on designing tables based on access patterns and building scalable models for high-performance reads and writes.

**Key concepts:**
- Query-driven schema design
- Partition keys and clustering keys
- Denormalized NoSQL modeling
- Distributed database concepts
